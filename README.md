# Half-Life Warmup: Car Parking Simulation

This is my warmup project for Hack Club's Half-Life! I built a functional car parking simulation using Wokwi. 

## [Click Here to Run My Live Wokwi Simulation](https://wokwi.com/projects/476887295698913281)

## Bill of Materials (BOM)

| Component Name | Quantity | Purpose |
| --- | --- | --- |
| IPS SCREEN SSD1306 | 1 | Displays all of the information like where to go |
| Ultrasonic Distance Sensor | 1 | Detects if a parking spot is taken |
| Servo Motor | 1 | Operates the parking lot entrance gate |
